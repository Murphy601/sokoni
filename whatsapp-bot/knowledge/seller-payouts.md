# Seller payouts

- After delivery confirmation (buyer YES or admin), seller net is scheduled for payout.
- Sellers withdraw from Seller Hub wallet / #payouts. Instant Paystack transfers when enabled; otherwise admin #paid queue.
- Item promos (% Set promo) lower the live STK price for that SKU only — not cart-wide coupons.
- Stock: set units or size/colour variants in Seller Hub → Stock. Low stock (≤2) triggers a WhatsApp alert.
- Shop promo banner is marketing copy on the public shop page; pair with item promo for a real price cut.
